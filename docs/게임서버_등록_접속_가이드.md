# 게임 서버 등록·로그인 접속 가이드

## 1. 전체 흐름

```text
언리얼 리슨/전용 서버
  ALobbyGM::BeginPlay
    -> UWebApiSubsystem::RequestGameServerRegistration
    -> POST /servers/register { server_address }
                         |
                         v
FastAPI 웹 서버가 현재 게임 서버 주소 보관
                         |
                         v
언리얼 클라이언트
  POST /login { user_id, passwd }
    <- { result, 회원 정보, server_address }
  UDataGameInstanceSubsystem에 주소 저장
  UGameplayStatics::OpenLevel(server_address)로 자동 접속
```

웹 서버 프로세스에는 한 개의 활성 게임 서버 주소를 보관합니다. 웹 서버를 재시작하면 게임 서버가 다시 등록해야 하며, `Lobby`가 시작될 때 자동으로 등록됩니다.

## 2. 웹 API

### 게임 서버 등록

`POST /servers/register`

```json
{
  "server_address": "203.0.113.10:7777",
  "registration_token": "optional-secret"
}
```

성공 응답:

```json
{
  "result": true,
  "message": "",
  "server_address": "203.0.113.10:7777"
}
```

포트를 생략하면 `7777`이 사용됩니다. `SERVER_REGISTRATION_TOKEN` 환경 변수가 비어 있지 않으면 같은 토큰을 보낸 게임 서버만 등록할 수 있습니다.

### 현재 게임 서버 조회

`GET /servers/active`

등록된 서버가 없으면 HTTP 200과 `result: false`를 반환합니다.

### 로그인

`POST /login`

```json
{
  "user_id": "tester",
  "passwd": "password"
}
```

성공 응답에는 현재 게임 서버가 있을 때 `server_address`가 포함됩니다.

```json
{
  "result": true,
  "message": "",
  "idx": 1,
  "nickname": "tester",
  "level": 1,
  "server_address": "203.0.113.10:7777"
}
```

## 3. 웹 서버 실행

Python 3.11 이상과 MySQL이 필요합니다.

```sql
CREATE DATABASE IF NOT EXISTS seul CHARACTER SET utf8mb4;
USE seul;
CREATE TABLE IF NOT EXISTS member (
  idx INT AUTO_INCREMENT PRIMARY KEY,
  user_id VARCHAR(100) NOT NULL UNIQUE,
  passwd VARCHAR(255) NOT NULL,
  nickname VARCHAR(100) NOT NULL,
  level INT NOT NULL DEFAULT 1
);
```

PowerShell에서 환경 변수와 의존성을 준비합니다.

```powershell
cd Server
py -m venv .venv
.\.venv\Scripts\pip.exe install -r requirements.txt
$env:DB_HOST = "127.0.0.1"
$env:DB_PORT = "3306"
$env:DB_USER = "root"
$env:DB_PASSWORD = "MySQL 비밀번호"
$env:DB_NAME = "seul"
$env:SERVER_REGISTRATION_TOKEN = "optional-secret"
.\run.bat
```

`run.bat`은 외부 언리얼 클라이언트가 접근할 수 있도록 `0.0.0.0:8080`에서 FastAPI를 실행합니다. 방화벽과 공유기에서는 TCP 8080을 허용해야 합니다.

## 4. 언리얼 설정과 실행

기본값은 `Config/DefaultGame.ini`의 `[WebApi]`에서 지정합니다.

```ini
[WebApi]
BaseUrl=http://127.0.0.1:8080
GameServerAddress=127.0.0.1:7777
RegistrationToken=
```

운영 환경에서는 코드나 설정 파일을 다시 만들지 않고 명령행으로 덮어쓸 수 있습니다.

```text
-WebApiBaseUrl=http://WEB_SERVER_IP:8080
-PublicServerAddress=PUBLIC_GAME_SERVER_IP:7777
-RegistrationToken=optional-secret
```

에디터 빌드에서 전용 서버 형태로 실행하는 예:

```powershell
& "C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe" `
  "C:\path\to\L20260713_Day03.uproject" /Game/Maps/Lobby -server -log `
  -WebApiBaseUrl=http://127.0.0.1:8080 `
  -PublicServerAddress=127.0.0.1:7777
```

리슨 서버는 기존 타이틀 화면에서 로그인 후 `StartServerButton`을 누르면 됩니다. `Lobby`가 리슨 모드로 열리면서 같은 등록 요청을 보냅니다.

Epic Games Launcher 엔진은 독립 `Server` 타깃 패키징을 지원하지 않습니다. `L20260713_Day03Server.Target.cs`로 패키징하려면 GitHub에서 빌드한 언리얼 소스 엔진을 사용해야 합니다. 리슨 서버와 `UnrealEditor -server` 검증에는 Launcher 엔진을 사용할 수 있습니다.

## 5. 클라이언트 동작

1. 타이틀 화면 `ServerIP`에 FastAPI 서버 IP를 입력합니다. `http://`와 포트는 입력하지 않습니다.
2. 아이디와 비밀번호로 로그인합니다.
3. 웹 서버가 반환한 `server_address`가 있으면 자동으로 게임 서버에 접속합니다.
4. 등록 서버가 없으면 로그인은 유지되고 `등록된 게임 서버 없음`이 표시됩니다. 이 상태에서는 `ConnectServerButton`이 비활성화됩니다.

인터넷을 통한 접속에는 게임 서버의 UDP 7777 포트도 방화벽과 공유기에서 허용해야 합니다.

## 6. 검증 방법

웹 API 단위 테스트:

```powershell
.\Server\.venv\Scripts\python.exe -m unittest discover -s Server\tests -v
```

수동 통합 테스트:

1. FastAPI 실행
2. 리슨/전용 서버 실행
3. `GET http://127.0.0.1:8080/servers/active`가 등록 주소를 반환하는지 확인
4. 별도 클라이언트에서 로그인
5. `Lobby`로 자동 접속되는지 확인

이번 구현 검증에서는 Python 테스트 3개가 통과했고, 수정한 C++는 UE 5.8 `L20260713_Day03Editor Win64 Development` 빌드에 성공했습니다.
